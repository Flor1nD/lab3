# Доска публикаций

Простое одностраничное приложение для работы с публикациями, использующее API JSONPlaceholder.

## Возможности

- **Загрузка публикаций** — получение последних 5 записей с сервера и отображение их в виде карточек.
- **Создание публикации** — отправка новой записи через POST-запрос с валидацией полей (заголовок и текст обязательны).
- **Уведомления** — отображение статусов загрузки, успешных операций и ошибок.
- **Повторная отправка** — кнопка «Повторить отправку» при ошибке сети.

## Запуск

- Откройте `index.html` в браузере
